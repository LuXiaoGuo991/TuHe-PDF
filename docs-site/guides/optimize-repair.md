## 压缩 PDF

[压缩 PDF](/compress-pdf) 通过重采样图片、精简内嵌资源来瘦身：

1. 选择文件后挑选压缩级别（轻度/标准/强力）
2. 运行后对比体积，不满意可换级别重试
3. 下载压缩结果

> 权衡：级别越高体积越小，图片清晰度损失越明显。含重要图表、印章的文档建议用轻度/标准，压缩后放大检查一遍。

**什么时候压不动？** 文字为主的 PDF 本身很小，压缩空间有限；体积大头通常是扫描图片，此时"强力压缩 + 降低 DPI"才有效。发微信/邮件有大小限制时，压缩后再[拆分](/split-pdf)也是常用组合。

## PDF 转 PDF/A（长期存档）

PDF/A 是 ISO 标准的存档格式：字体全部内嵌、禁用加密与外部依赖，保证几十年后仍能原样打开。

1. 打开 [PDF 转 PDF/A](/pdf-to-pdfa)
2. 选择目标级别：**PDF/A-2b**（外观保真，常用）或 PDF/A-1b / 3b（3b 支持内嵌附件）
3. 转换后下载；政务归档、合同留存、论文提交常要求此格式

## 修复 PDF

文件打不开、报错、页面缺失时，用[修复 PDF](/repair-pdf)尝试恢复：

1. 选择损坏的文件，工具会重建 PDF 的交叉引用表与对象结构
2. 能恢复多少取决于损坏程度——建议立刻操作，避免文件进一步损坏
3. 修复成功后，另存一份并用[查看元数据](/view-metadata)确认文档结构正常

## 线性化 PDF

[线性化 PDF](/linearize-pdf)重排文件结构，使浏览器可以"边下边显示"第一页，无需等待整个文件下载完成。网站发布 PDF 资料、大文件在线预览前建议做一次。

## 扫描件修整流水线

扫描质量差的文档，推荐按以下顺序处理：

1. [校正 PDF](/deskew-pdf)——自动纠偏倾斜页面
2. [OCR 文字识别](/ocr-pdf)——叠加文字层（见[组织与管理指南](/docs/guides/organize-manage)）
3. [移除空白页](/remove-blank-pages)——删掉扫描产生的空白页
4. [压缩 PDF](/compress-pdf)——控制体积
5. 需要归档再加一步 [PDF/A 转换](/pdf-to-pdfa)

以上顺序可用[工作流构建器](/pdf-workflow)串成一条流水线。

## 栅格化与字体转轮廓

- **[栅格化 PDF](/rasterize-pdf)**：把每页渲染成图片再打包为 PDF——文字不再可选，但任何设备打开效果 100% 一致；也用于防止他人复制内容
- **[字体转轮廓](/font-to-outline)**：文字转为矢量路径，印刷厂投稿、跨平台交付时防止对方缺字体导致版式变化
