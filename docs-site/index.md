## 欢迎来到图合PDF文档

图合PDF工具（TuHe PDF）是一个**完全在浏览器本地运行**的在线 PDF 工具箱：合并、拆分、压缩、转换、OCR 文字识别、编辑注释、加密签名等 100+ 项能力，全部通过 WebAssembly 在你的设备上完成——**文件不会上传到服务器**。

## 从这里开始

- [快速开始](/docs/getting-started)：认识工作台界面，3 分钟完成第一次 PDF 处理
- [常见问题](/docs/faq)：隐私、文件大小、浏览器兼容、OCR 语言等高频疑问
- [自部署](/docs/self-hosting)：用 Docker 在你自己的服务器上部署图合PDF

## 特色能力

- **PDF 工作流构建器**：用可视化节点编辑器把多个处理步骤串成流水线，见 [组织与管理指南](/docs/guides/organize-manage)
- **完全本地处理**：无文件上传、无第三方分析追踪，详见[隐私政策](/privacy)
- **多语言界面**：支持简体中文、繁體中文、English 等 19 种界面语言，右上角随时切换
- **深色/浅色主题**：跟随你的偏好自动保存
