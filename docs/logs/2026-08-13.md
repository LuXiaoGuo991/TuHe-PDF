### 背景与目标

针对前一轮审查发现的主题 iframe 不同步、WCAG AA 不达标、复杂工具页硬编码颜色、`zh-TW` 人工复核缺失和迁移门控误报，制定可分批实施、独立验证和逐步回滚的解决方案。本任务未查阅历史日志；仅基于当前源码、`docs/ROADMAP.md` 和 GitNexus 调用关系进行影响分析，不修改功能代码。

### 影响分析与决策

- GitNexus 显示 `initTheme` 为 LOW 风险，只有 `src/js/main.ts:init` 一个直接调用者；`initWorkbench` 也为 LOW 风险且仅由 `main.ts:init` 调用。主题同步应只修改 `src/js/utils/theme.ts`，不进入 600 多行的工作台标签页流程。
- 将主题应用与持久化分离：初始化和 `storage` 事件只应用主题，用户点击才写 `localStorage`，避免 iframe 写回循环；保留现有 `tuhe.theme` 作为 canonical key，或在必须改名时采用双读单写迁移，不能直接丢弃既有偏好。
- 不直接改写共享 `--color-success`、`--color-warning`、`--color-danger`、`--color-info`；新增 `--color-on-action`、`--color-on-danger` 和 `--color-status-*-text`，仅让按钮与文字组件消费对应 token，避免影响进度条、图例和 PDF 内容颜色。
- `compare-pdfs.html`、`pdf-workflow.html` 需区分主题 UI、PDF 纸张/差异叠层和工作流类别色；固定业务颜色转为命名的页面级 custom properties 并记录豁免，只有 UI chrome 接入全局主题。`pdf-layers.html` 的颜色均按 UI chrome 迁移。
- `scripts/migrate-visual-batch.mjs` 的 Windows 路径需先标准化为 `/`；当前 `semanticColorExclude` 使用 POSIX 路径而 `path.relative` 返回反斜杠，是排除逻辑失效和 4 个误报的根因。最终门控应支持带理由的精确豁免，并扫描内联 CSS，不再只匹配 Tailwind class。
- `zh-TW` 采用工具/命名空间小批次人工复核；OpenCC 只生成候选 diff，不自动覆盖已审文案。清单记录实际 4219 个键的批次、审阅人、日期和状态，并增加占位符、HTML 标记与键集合一致性检查。

## 15:46 Phase 3 修复结果复审

### 背景与目标

复审用户提供的 5 项修复摘要与当前未提交工作树，确认实现是否真的通过验证、是否存在脚本通过但运行时仍回归的情况。本任务未查阅历史日志；检查了当前差异、源码、测试脚本和本地命令结果。

### 审查结论

- iframe 主题同步实现方向正确：`applyTheme` 不写存储，点击是唯一写入口，iframe 监听 `storage`。但新增 `phase2-visual-check.mjs` 的 `validateThemeSync` 当前实际失败，`waitForSelector` 后立即从 `page.frames()` 查找 frame，存在加载竞态；应改为等待 iframe `load` / `contentFrame()` 就绪后再检查。
- 对比度 token 数值检查通过，但约 110 个页面的主按钮仍同时包含 `.ui-button-primary` 与 `.ui-text-primary`；后定义的 `.ui-text-primary`（`styles.css` 2158 行附近）会覆盖按钮规则的 `--color-on-action`。因此脚本的 14 项 token 对通过，不等于实际按钮都满足 WCAG AA。
- `check-contrast`、`migrate-visual-batch --check` 和 `check-zh-tw-review` 均未接入 `npm run build`；后续构建不会自动执行这些 Phase 3 门控。
- `parse5` 与 `postcss` 仅作为 `jsdom` / `vite` 的传递依赖出现，未声明为项目直接依赖；迁移脚本依赖传递依赖的扁平化结果，干净安装或依赖升级可能失效。
- zh-TW 门控按预期失败：0/4219 键已复核，123 个命名空间未完成，另有 18 个占位符问题和 1 个快捷键问题。`SHORTCUT_TOKENS` 目前不包含注释中声称覆盖的 `Enter`、`Shift`、`Tab`、`Alt` 等 token；manifest 只保存命名空间，不机器校验清单中的复核人、日期和键数。

### 命令与验证

- `npm install`：通过。
- `npm run setup:wasm`：通过，固定 WASM 资源 hash 校验成功。
- `npm run check:contrast`：通过，14 项检查全部通过；未覆盖实际 CSS cascade。
- `node scripts/migrate-visual-batch.mjs --check`：通过，473 个文件、0 个待迁移、0 个未批准颜色。
- `node scripts/check-zh-tw-review.mjs`：按预期退出 1，报告 0/4219 已复核、123 个未复核命名空间和 19 个审计问题。

### 风险与后续

- 当前建议：主题同步先修复视觉脚本竞态；删除批量页面上的 `.ui-text-primary` / `.ui-text-danger` 覆盖，或提供更高优先级且用途明确的按钮规则，再用浏览器 computed style 做对比度断言。
